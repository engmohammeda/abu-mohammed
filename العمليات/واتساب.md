# واتساب

الاسم الظاهر: `البخيتي للبناء والمقاولات`. الرقم `0531060401`.

## الترحيب

```
أهلاً
البخيتي للبناء والمقاولات — الرياض.
حجر تراثي، جدران، وأسوار.
أرسل صورة المكان وأعطيك السعر.
```

## الغياب

```
خارج الوقت الآن، من 7 الصباح إلى 10 الليل.
رسالتك وصلت، وأرد عليك أول ما أفضى.
```

## الردود السريعة

| الاختصار | النص |
|---|---|
| `/سعر` | أرسل نوع الشغل، والحجم التقريبي، وصورة المكان، واللوكيشن. أعطيك السعر على شغلك. |
| `/حجر` | حجر تراثي: جدران، واجهات، وأسوار. أرسل صورة المكان والمقاس. |
| `/بلك` | بناء بلك: يومية أو مقطوعية. أرسل المقاس وصورة المكان. |
| `/جدار` | جدران وفواصل. السعر يُكتب من البداية. أرسل الطول والارتفاع وصورة. |

## أول رد

```
أهلاً
عشان السعر يكون على مكانك، لا رقماً عامّاً:
1) حجر، جدار، سور، أو بلك؟
2) الحجم التقريبي؟
3) صورة المكان واللوكيشن؟
```

## بعد يوم، مرة واحدة

```
وصلك السعر؟
أي سؤال عن البنود أنا حاضر.
إذا ناسبك نثبت الاتفاق.
```
