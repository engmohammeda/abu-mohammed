# سجل العملاء

كل اسم يدخل في [[سجل-العملاء.csv]] في نفس اليوم. لا صفوف وهمية، ولا تقييم مكتوب بيد المعلم.

| العمود | المعنى |
|---|---|
| التاريخ | يوم أول رسالة |
| الاسم | الاسم الأول يكفي |
| الجوال | كما كتبه |
| الحي | إن ذكره |
| نوع الشغل | مشبة، فرن، جدار، فاصل، شواية |
| المصدر | حراج، حالة، قروب، جار موقع، توصية |
| الحالة | جديد، سعر مرسل، موافق، قيد التنفيذ، مسلم ومدفوع، يوصي، متوقف |
| السعر المرسل | الرقم المكتوب |
| متابعة قادمة | تاريخ واحد، لا سلسلة إلحاح |
| ملاحظة | تفصيلة المكان |
| النتيجة | اتفاق، اعتذار، أو صمت |

مراجعة الثلاثاء من [[الهدف-والأسبوع]]: الرسائل، سرعة الرد، الأسعار المرسلة، الموافقات، والمبالغ المتأخرة. الهدف أن يبقى المتأخر صفراً.

قالب رسالة عميل جديد في [[قالب-عميل]] إن احتجت ملاحظة مستقلة لكل زبون.
