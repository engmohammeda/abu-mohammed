# الألوان

بسيط، حرفي، دافئ. الاحتراف هنا نظافة المشهد ووضوح الرقم، لا رخام وذهب مبهرج.

| الدور | اللون | الاستعمال |
|---|---|---|
| فحم | `#1C1917` | خلفيات النص والبطاقة |
| طوب | `#8C3A2F` | الحرفة، عناوين الخزنة |
| رمل | `#E7D7C1` | مساحات هادئة |
| كريم | `#F3EDE0` | نص على الغامق |
| جمر | `#C4A15A` | لمسة فقط |
| ليل | `#1A2332` | لقطات المساء |

المشهد: شتاء الرياض، طوب حراري، طين، حجر، مدخنة واضحة، مجلس أرضي بسيط، حوش أو مزرعة. ممنوع قصر، ثريا، سقالة عمارة، أسلوب غربي، كرتون، ونص لاتيني عشوائي.
