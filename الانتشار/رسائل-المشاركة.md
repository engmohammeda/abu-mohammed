# رسائل المشاركة

ترسل خارج حراج
ضع رابط الإعلان في سطر لحاله
لا تكتب رابط قروب داخل حراج
النصوص بلا ترقيم وبلا تنصيص

## للقروب

```
السلام عليكم
البخيتي للبناء والمقاولات في الرياض
أعمال البناء والتشطيب
حجر تراثي وأسوار وبلك ولياسة
هذا الإعلان
رابط إعلان حراج

```

## للحالة

```
البخيتي للبناء والمقاولات
```
