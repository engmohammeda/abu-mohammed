# إعلان الأفران

هذا الملف وحده يكفي لهذا الإعلان. صوره في المجلد `صور` بجانبه. لا تُخلط مع إعلان آخر.

## العنوان

```
فرن طين وفرن حطب في الرياض أفران مندي وخبز أبو محمد
```

## الوصف — انسخه كما هو

```
أبو محمد معلم مباني
أشتغل أفران حطب في الرياض
طين وحجر وطوب حراري
خبز ومندي ومشويات
للبيت أو الاستراحة أو المزرعة
الحجم على مكانك
أرسل صورة المكان وأقولك السعر
إذا اتفقنا أمشي على كلامنا
0531060401
الرياض
```

## كلمات آخر الإعلان

```
فرن طين، فرن حطب، أفران مندي، فرن خبز، أبو محمد معلم مباني
```

## عند النشر

- قسم **خدمات**، المدينة **الرياض**، التعليقات مفتوحة.
- هذا ملف مستقل. لا تخلط صوره مع إعلان آخر، ولا تنسخ نصه داخل إعلان ثانٍ.
- الرد يبدأ داخل حراج، ثم يُعطى الرقم.
- لا تُكتب في الإعلان: ترميم، عرض، خصم، مجاني، معاينة، صغير، أو وعد بمدة الشغل.

## الرد داخل حراج

```
السلام عليكم
أشتغل أفران طين وحطب في الرياض
فرن للبيت أو الاستراحة أو المزرعة
أرسل صورة المكان والمقاس التقريبي
أقولك السعر على شغلك
0531060401
```
