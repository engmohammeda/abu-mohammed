# القروبات

> [!danger] داخل حراج لا يُعلن عن قروب
> الإعلان عن مجموعات سبب حظر. القروب أداة خارج حراج فقط. رابط الإعلان هو اللي يننشر، لا رابط قروب داخل الإعلان.

## أي قروب

| مناسب | غير مناسب |
|---|---|
| مزارع الخرج وما حول الرياض | قروب مقاولين |
| استراحات وشمال الرياض | وسيط يجمع أرقام |
| حي أو مجلس يعرفه المعلم | قروب عام يُبلغ عن السبام |
| أهل وجيران | حسابات تبيع تفضيل |

لا تخترع روابط. كل موضع يُسجّل هنا قبل النشر الثاني:

| الموضع | نوع الناس | نُشر؟ | كم رداً | القرار |
|---|---|---|---|---|
| أهل / جيران | صاحب حاجة | | | |
| | | | | |

أي موضع بلا رد يُوقف يوم الثلاثاء. أي موضع وسيط يُعلَّم «لا تُعد» فوراً.

الرسالة جاهزة في [[رسائل-المشاركة]]، والرابط يُلصق من [[روابط]] بعد صدور الإعلان.

وتيرة آمنة: 3 مواضع اليوم، ثم موضع واحد جديد يوم الاثنين. لا حملة لصق جماعي.
