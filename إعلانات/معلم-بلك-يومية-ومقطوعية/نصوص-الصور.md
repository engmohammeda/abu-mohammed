# نصوص الصور — إعلان معلم بلك باليومية والمقطوعية

هذا الملف هو سجل كل كلمة مكتوبة على الصور. أداة `أدوات/فحص-المستودع.py` تقرأ الكتل التالية وتطبّق عليها قائمة المنع قبل النشر، لأن الصورة نفسها لا تُفحص بالـ OCR.

القاعدة: كتابة إنسانية قصيرة تصف أثر الشغل، والصورة نفسها تبيّن الإتقان. بلا ترقيم وبلا تنصيص وبلا إيموجي، ولا سعر ولا مدة ولا ادعاء إنجاز.

## العلامة المائية المكتوبة

كل صورة تحمل ثلاث طبقات بنفس النص:

```
أبو محمد معلم بلك ومباني
0531060401
```

الشريط السفلي، والختم داخل البكسلات فوق الشريط، والتكرار القطري بشفافية 18 بالمئة. الرقم بلا مسافات وباتجاه LTR.
