## للوكيل

1. اقرأ `ابدأ-من-هنا.md` قبل أي تعديل.
2. لا تُرجع هوية «مشبات وأفران» إلى الغلاف أو البايو أو العلامة.
3. كل إعلان في مجلده تحت `إعلانات/`.
4. الغلاف والصورة الشخصية في `المتجر/` فقط.
