# إعلان الأفران

هذا الملف وحده يكفي لهذا الإعلان. صوره في المجلد `صور` بجانبه. لا تُخلط مع إعلان آخر.

## العنوان

```
فرن طين الرياض | أفران حطب ومندي وخبز | البخيتي للبناء
```

## الوصف — انسخه كما هو

```
فرن حطب يجمع العيلة.

نبني أفران طين، وحجارة، وطوب حراري:
▪️ خبز، مندي، ومشويات
▪️ للبيت، والاستراحة، والمزرعة
▪️ الحجم على مكانك، والتشطيب على ذوقك

أرسل صورة المكان والحجم التقريبي، وأعطيك السعر الواضح.
📱 0531060401
```

## كلمات آخر الإعلان

```
فرن طين، فرن حطب، أفران مندي، فرن خبز، البخيتي للبناء والمقاولات
```

## عند النشر

- قسم **خدمات**، المدينة **الرياض**، التعليقات مفتوحة.
- هذا ملف مستقل. لا تخلط صوره مع إعلان آخر، ولا تنسخ نصه داخل إعلان ثانٍ.
- الرد يبدأ داخل حراج، ثم يُعطى الرقم.
- لا تُكتب في الإعلان: ترميم، عرض، خصم، مجاني، معاينة، صغير، أو وعد بمدة الشغل.
