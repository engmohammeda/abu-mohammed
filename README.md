# أبو محمد معلم بلك ومباني

معلم بلك معلم مباني في الرياض — `0531060401`

هذا مستودع العمل الكامل: الموقع، الإعلان، الهوية، والأدوات. يُنشر الموقع على GitHub Pages من مجلد `موقع/`.

**الرابط:** https://engmohammeda.github.io/abu-mohammed/

النشر تلقائي عبر `.github/workflows/pages.yml` عند أي تعديل في `موقع/`.

### تشغيل الموقع محلياً

```bash
cd موقع
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

python3 أدوات/وسم-معلم-بلك-يومية-ومقطوعية.py
