# دليل الموقع

الموقع في `موقع/` ويُنشر على GitHub Pages تلقائياً.

**الرابط:** https://engmohammeda.github.io/mydad/

## البنية

| الملف | الاستخدام |
|---|---|
| `index.html` | الرئيسية |
| `balk.html` | معلم بلك في الرياض — الصفحة الأقوى للسيو |
| `about.html` | تعريف المعلم — تستهدف الاسم |
| `khadamat.html` | الخدمات |
| `aamal.html` | الأعمال والصور |
| `sayr.html` | طريقة العمل |
| `tawasel.html` | التواصل ونموذج الرسالة |
| `404.html` | صفحة الخطأ |
| `css/site.css` | الستايل |
| `js/site.js` | قائمة الجوال |
| `خطوط/` | خطوط IBM Plex Arabic الأربعة |
| `صور/` | صور الموقع |
| `robots.txt` | ملف الزحف |
| `sitemap.xml` | خريطة الموقع |
| `favicon.svg` | أيقونة الموقع |

## ما لا يدخل الموقع

لا ذكر للمواد، ولا سعر عام، ولا وعد بمدة، ولا شروط دفع. الدفع في `العمليات/قواعد-الدفع.md`. ولا فواصل ولا مكنوس ولا نظافة ولا ترتيب.

## الأسلوب

كل نص يتبع `الهوية/قواعد-الكتابة.md`. بلا ترقيم. السطر الجديد هو الفاصل.

## النشر

سير النشر في `.github/workflows/pages.yml`. يُشغَّل عند أي تعديل في `موقع/` على فرع `main`.

إن توقف النشر، تحقق أولاً من أن Pages مفعّل على المستودع بمصدر **GitHub Actions** لا «Deploy from a branch».

## المحلي

```bash
cd موقع
python3 -m http.server 8000
```

## تغيير النطاق

canonical وOpen Graph مضبوطان على `https://engmohammeda.github.io/mydad/`. إذا انتقلت إلى نطاق خاص يُحدَّث في `أدوات/تحسين-السيو.py` ثم يُعاد تشغيله، ويُحدَّث `robots.txt` و`sitemap.xml` معه.
