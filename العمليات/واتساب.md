# واتساب

الاسم الظاهر البخيتي للبناء والمقاولات
الرقم 0531060401
النصوص بلا ترقيم وبلا تنصيص

## الترحيب

```
أهلا
البخيتي للبناء والمقاولات
أعمال البناء والتشطيب في الرياض
أرسل صورة المكان وأقولك السعر
الأهم الثقة والأمانة
```

## الغياب

```
رسالتك وصلت
أرد عليك أول ما أفضى
```

## الردود السريعة

| الاختصار | النص |
|---|---|
| سعر | أرسل نوع الشغل والمقاس وصورة المكان واللوكيشن وأقولك السعر على شغلك |
| حجر | حجر تراثي جدران وواجهات وأسوار أرسل صورة المكان والمقاس |
| بلك | بناء بلك يومية أو مقطوعية أرسل المقاس وصورة المكان |
| لياسة | لياسة وتشطيب أرسل صورة المكان والمقاس |
| جدار | جدران وفواصل أرسل الطول والارتفاع وصورة المكان |

## أول رد

```
أهلا
عشان السعر يكون على مكانك
حجر أو سور أو بلك أو لياسة أو مشب
المقاس التقريبي
صورة المكان واللوكيشن
إذا اتفقنا نثبته هنا وأمشي على كلامنا
```
