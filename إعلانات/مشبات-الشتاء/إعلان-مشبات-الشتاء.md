# إعلان مشبات الشتاء

هذا الملف وحده يكفي لهذا الإعلان. صوره في المجلد `صور` بجانبه. لا تُخلط مع إعلان آخر.

## العنوان

```
معلم مشبات ومدافئ في الرياض حطب وطوب وحجر أبو محمد
```

## الوصف — انسخه كما هو

```
أبو محمد معلم مباني
أشتغل مشبات حطب في الرياض
طوب وحجر وطين
في المجلس أو الحوش أو المزرعة
الحجم على مكانك
أرسل صورة المكان وأقولك السعر
إذا اتفقنا أمشي على كلامنا
الأهم الثقة والأمانة
0531060401
الرياض
```

## كلمات آخر الإعلان

```
مشبات الرياض، مشبات حطب، مشبات طوب، مشبات حجر، مشب، أبو محمد معلم مباني
```

## عند النشر

- قسم **خدمات**، المدينة **الرياض**، التعليقات مفتوحة.
- هذا ملف مستقل. لا تخلط صوره مع إعلان آخر، ولا تنسخ نصه داخل إعلان ثانٍ.
- الرد يبدأ داخل حراج، ثم يُعطى الرقم.
- لا تُكتب في الإعلان: ترميم، عرض، خصم، مجاني، معاينة، صغير، أو وعد بمدة الشغل.

## الرد داخل حراج

```
السلام عليكم
أشتغل مشبات حطب في الرياض
طوب أو حجر أو طين
في المجلس أو الحوش أو المزرعة
أرسل صورة المكان والمقاس
أقولك السعر على شغلك
0531060401
```
